# SMART-DOOR-LOCK
Smart Door Lock is an electronic door locking system based on an Arduino Nano that uses a matrix keypad for password input. When the correct password is entered, the servo motor unlocks the door mechanism and the buzzer provides an access notification. If an incorrect password is entered, the buzzer sounds for a longer duration to indicate that access is denied. A button is also provided to unlock the door from the inside without entering a password.

Main components: Arduino Nano, Matrix Keypad, Servo Motor, Buzzer, and Button.
